An 8-bit pixel newspaper that sums up Tuesday 24 November 2026 in one
image: 38 dated world-news stories across 9 regions, with 15 drawn
pixel icons, a world map with pins at their true places, and a date
check that names the wrong-day stories it left out.

## Run

`main.py` (Python 3.13, standard library only) decodes `entry.png.b64` and
writes the newspaper image to `/output/entry.png`. No network is used,
and two runs write the same bytes.

## Inside the image

Three leads — the Cikande factory fire, the Huawei verdict and four
tankers hit by mines in the Strait of Hormuz — plus 12 more stories,
a map of where it happened and 23 more stories in the ALSO list.
Unconfirmed claims are labelled as such in the text.
