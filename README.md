An 8-bit pixel newspaper summing up the world's news of Tuesday 24 November
2026 in one image: 36 stories, led by the Cikande factory fire toll rising
to 26, the Huawei verdict in New York, and four tankers hit by mines in the
Strait of Hormuz — plus a world map with numbered pins and a date check box.

## Run

`main.py` (Python 3.13, standard library only) decodes `entry.png.b64` and
writes the newspaper image to `/output/entry.png`. No network is used, and
two runs write byte-identical output.

## Contents

- `main.py` — the entry program (decoder)
- `entry.png.b64` — the newspaper image, base64 on one line
